Feature guide🌍 Public page

The complete catalogue of what this studio can do: every module, what it is for, who can reach it and which pages it connects to, generated from the platform itself so it can never drift out of date. Search it, filter it by role, and open any page straight from its entry. This is the fastest way for a new tutor to learn the studio, and the fastest way for an owner to discover a feature they are paying for and not using. Open to anyone, no sign-in needed. It is deliberately indexed by search engines so families can find the studio.

Who it is for. Owner and admin. This is configuration and governance, not day-to-day teaching.

Why it matters. Configuration decides who can see what. A mistake here is a privacy incident, so every change is written to the activity log.

How to use this page
  1. Only an owner or admin should change anything on this page.
  2. Read the note beside each setting before you touch it.
  3. Save, then reload any normal page to confirm the change took effect.
  4. If something looks wrong afterwards, the activity log records who changed what and when.
What each role sees here
  • Owner: Full access, and can edit the content behind it in Settings.
  • Tutor: Full access — it is a public page.
  • Parent: Full access — it is a public page.
  • Learner: Full access — it is a public page.
