Security & compliance🎓 Staff only

The studio's safety console. It shows what an anonymous stranger can reach, who has been touching learner records, failed sign-in attempts, the consent you hold and the data requests families have made. It also produces the two documents a regulator or a worried parent will ask for: a complete export of everything held on one learner, and an anonymised export for analytics. What you can do here: Download anonymised data, Download full record, Refresh status, Run security scan, Show audit trail, Start enrolment, Verify and finish. Requires sign-in as a tutor, admin or owner. Families cannot open it and the database refuses their queries even if they try the URL directly.

Who it is for. Owner and administrator only. Every function behind this page re-checks your role inside the database, so it cannot be reached by editing the page in a browser.

Why it matters. You hold children's names, dates of birth, guardian phone numbers, addresses, exam scores and safeguarding notes. Nigeria's NDPA 2023 gives families the right to see and correct that data, and the same duty exists under GDPR and FERPA elsewhere. The control every one of those regimes names first is an immutable audit trail — a record of who accessed what that the accessor cannot edit or delete.

How to use this page
  1. Press Run security scan. It asks the database what an anonymous visitor can reach; everything listed should be something a stranger is supposed to use.
  2. Confirm Tables without row-level security is empty. Anything listed there is readable by anyone holding the public key, which is printed in your page source.
  3. Review failed sign-ins. Three or more failures against one address is either a forgotten password or somebody guessing.
  4. Use the Audit trail to answer "who changed this?" — filter by table and record id and read the before-and-after of every field.
  5. When a family asks what you hold on their child, use Export a learner's full record. The statutory deadline is 30 days here and 45 under FERPA; this takes seconds.
  6. Log every request in Data requests so the clock is visible and nothing is missed.
  7. Record photo, trip and marketing permissions in Consent, storing the signed form as a Drive link — this studio never accepts uploads.
What each role sees here
  • Owner: Full access.
  • Tutor: Full access for the learners and groups assigned to them, and nothing else.
  • Parent: No access.
  • Learner: No access.

🔐 Two-factor authentication (2FA)

A password alone protects children's records. Two-factor adds a six-digit code from an app on your phone, so a stolen password is not enough on its own. The codes are generated by Supabase Auth, which is included in the free tier — there is no SMS bill and no third-party service. This studio stores only whether you have enrolled; it never sees or stores a secret or a code.

How to turn 2FA on — step by step
  1. Install a free authenticator app: Google Authenticator, Microsoft Authenticator, Authy or 1Password. Any app that follows the RFC 6238 standard works.
  2. Press Start enrolment below. A QR code appears.
  3. Scan the QR code with the app. It will start showing a six-digit code that changes every thirty seconds.
  4. Type the current code into the box and press Verify and finish.
  5. From then on, signing in asks for a code as well as your password.
  6. Write down your recovery route. If you lose the phone, an administrator must reset your factor in the Supabase dashboard — there is no self-service bypass, because a bypass would defeat the whole point.

Append-only. Nobody, including an administrator, can edit or delete an entry through the application; the database refuses it with a trigger.

📤 Export a learner's full record

Everything this studio holds on one learner, as a single JSON file. This is what satisfies a “right to inspect” request.

📊 Anonymised export

Same numbers, no identities. Each learner becomes a stable SHA-256 pseudonym, so trends survive but nobody can be identified. Use this when sharing results with a partner, a funder or a marketing page.

📋 Data requests

Log every access, correction or erasure request a family makes. The due date is set 30 days ahead automatically.

✍️ Consent records

Proof that you were allowed to photograph a child, take them on a trip, or contact a family for marketing. Store the signed form as a link (Drive or https) — this studio never accepts uploads.
