ℹ️ What is this page?
Reading assignments📖 Staff set · learners read & tick

Pre-class reading and video links tied to the next SOW topic. Staff set an assignment with one or more links; learners open each link and tick it ✓ done when finished, and their progress is recorded instantly. V49 fixed the bug where students saw an assignment but no links at all — reading items are now visible to the class they belong to, and learners can tick their own progress.

Who it is for. Tutors set the reading; learners do it and tick it off; parents watch it happen.

Why it matters. Reading is set BEFORE the lesson it feeds — a learner who arrives having read is a learner the lesson can lift.

How to use this page
  1. Staff: pick the class and (optionally) the SOW topic, give the assignment a title and a due date.
  2. Add the first link (article / video / pdf / playlist — Drive, YouTube or any https URL; never an upload) and click Save assignment + item.
  3. More links for the same assignment? Save again with the same title — or open the assignment and add items from its card.
  4. Learners: open each link, read or watch, then click ✓ I read this. Your tick is saved to the database instantly and your tutor can see it.
  5. Parents: a read-only view of the same cards, for your own children only.
What each role sees here
  • Owner: Set, edit and delete reading across every class.
  • Tutor: Set, edit and delete for the classes assigned to them.
  • Parent: Read-only — their own children’s assignments, links and progress.
  • Learner: Their own assignments and links, and can tick items done.
