Register for a free class🌐 Public

The public sign-up page for a free class. Opened with a registration link, it shows what the class is, when it runs and on which platform, then collects the few details needed to register and issues a registration number on the spot, together with the joining links. No portal account is required — anyone with the link can register.

Who it is for. Anyone with the link. No account and no sign-in are required.

Why it matters. A free class advertised on WhatsApp converts badly if the first step is "create an account". This page asks for a name and a way to reach the student, and nothing else that is not needed.

How to use this page
  1. Open the link you were given.
  2. Read what the class covers, when it runs and where it happens.
  3. Fill in your details. A parent or guardian must consent when the class is for minors.
  4. Press Register and save the registration number you are shown.
  5. Use the joining links on the confirmation to reach the class and the group chat.
What each role sees here
  • Guest (no account): Full registration form for the linked free class.
  • Parent / learner: Same public form — no portal login required.
  • Tutor / owner: Same page; manage cohorts from Free class cohorts.
