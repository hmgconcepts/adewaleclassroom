📡 Tablet Social Live — No OBS

Broadcast a live Classroom Deck lesson from your tablet to YouTube, Facebook, Instagram, TikTok or a custom RTMP destination. The built-in path is Classroom Deck tablet → WebRTC relay → social RTMP platforms.

1. Direct from tablet: the 5-step quick start

  1. Deploy the relay once: upload the included relay/no-obs-social-relay/ folder to a free/low-cost VM with HTTPS (Vercel/Render/fly.io/a $4 VPS all work). Note its address — that is your gateway URL.
  2. On the platform(s) you want (YouTube, Facebook, TikTok, Instagram…), start creating a live stream and copy the stream key it shows you.
  3. Open Teacher Studio on your tablet → ⚙ Settings → 📡 Tablet Live.
  4. Paste your gateway URL and each platform key into a destination row (see the field guide below — the server URL fills itself in).
  5. Tap ▶ Start social live. Classroom Deck sends the lesson canvas + mic to the relay; the relay publishes to your platforms.
Why a relay is needed: the modern web browser can send WebRTC, but social platforms still commonly require RTMP/RTMPS ingest. The relay converts WebRTC to RTMP without needing OBS on the tablet.
Already set up on another device? Sign in with your ADEWALE CLASSROOM account — the gateway, secret and every key are restored automatically, and there is a ☁️ Restore from cloud button in the Tablet Live panel to pull them on demand.

2. Every field explained — Settings → 📡 Tablet Live

Each row below matches a field in the Tablet Live panel exactly, with a copy-paste example. Nothing is assumed.

FieldWhat it is · example
Relay gateway URLThe HTTPS address of YOUR deployed relay (step 1 above). Example: https://class-relay.yourdomain.com — the WHIP pattern is https://YOUR-RELAY-DOMAIN/rtc/v1/whip/?app=live&stream=classdeck. Must start with https://: the browser blocks an http:// gateway on an HTTPS page, and the preflight catches it before you stream.
Gateway secretThe shared password you set on the relay (its SECRET environment variable) — only people who know it can publish through your relay. Example: a-long-passphrase-only-you-know. Leave empty if your relay does not require one.
Stream nameA name for THIS device’s feed — letters, digits and dashes only. Pre-filled as classdeck-<room code>. Example: classdeck-math10a. Two teachers streaming at the same time must use different stream names.
FormatLandscape 16:9 for YouTube / Facebook / Twitch, or Vertical 9:16 for TikTok / Instagram (the class canvas is framed full-height with your camera picture-in-picture).
Frame rate10 fps for weak/mobile upload · 15 fps recommended · 24 fps smooth · 30 fps only on strong upload. The panel shows an honest bitrate hint for each choice.
Destination — platformPick YouTube, Facebook, TikTok, Instagram, Twitch, Kick or Custom RTMP. The correct RTMP/RTMPS server is filled in automatically — you never type a server URL by hand (hand-typed servers are the #1 cause of failed streams).
Destination — keyThe stream key from the platform dashboard (YouTube → Go Live → Stream key; Facebook → Live Producer → Use stream key; TikTok → Live Center; Instagram → Live Producer). Example (YouTube): ab3d-1234-5678-9def. Keys are masked and never logged; pasting a full rtmp://… URL by mistake is understood, not rejected. YouTube keys go stale after a few uses — copy a fresh one if the stream is refused.
Destination — serverAuto-filled from the preset (YouTube rtmp://a.rtmp.youtube.com/live2, Facebook rtmps://live-api-s.facebook.com:443/rtmp/…). Only Custom RTMP asks you to type one — paste it exactly as your provider shows it. The full publish URL sent to the relay is server/key.
⚡ Smart paste boxPaste anything — a bare key, a full rtmp(s)://server/app/KEY URL, or the whole block copied from the platform page (even when it mentions the platform by name) — and Classroom Deck works out the platform, server and key and adds the row for you.
💾 Save settings · ☁️ RestoreSave keeps the setup on this device (and pushes it to your ADEWALE CLASSROOM account when signed in). Restore from cloud pulls the gateway, secret and keys back onto THIS device — the button to press on a new tablet after signing in.
Remember on this deviceChecked = the full setup (including keys) is stored on this device so it survives a refresh. Unchecked = only the gateway, stream name and format are kept, and the keys are re-entered next time.
▶ Start · ■ Stop · 🩺 Check relayStart runs a preflight first (empty keys, duplicate platforms, http gateway and TikTok-landscape warnings are caught BEFORE a byte leaves the tablet), then begins the broadcast. Stop ends it. Check relay tests whether the gateway answers at all.
First time? Do one dry run: start the stream, confirm the preview appears on the platform, stop it, delete the dry-run recording. Keys are per-stream on YouTube and Instagram — generate fresh ones for the real class.

3. Full tablet screen vs Classroom Deck screen

On many Android tablets, browser security does not expose full-system screen capture to websites. Classroom Deck therefore provides two routes:

  • Classroom Deck workspace capture: always available because the app captures its own teaching canvas.
  • Full tablet screen attempt: available only if the tablet/browser supports getDisplayMedia.
If full Android screen capture is not available, your students/social audience still see the whole Classroom Deck teaching workspace — whiteboard, PDFs, browser cast, notes, toolkit, camera, captions and overlays.

4. Social platform notes

▶ YouTube

Use YouTube Studio/Live Control Room to create a stream and copy the RTMP server + key. Paste the full publish URL into Tablet Live.

f Facebook

Use Facebook Live Producer. Copy the secure RTMPS publish URL/key. Some workflows require you to click Go Live in Facebook after the preview appears.

📸 Instagram

Use a professional/creator account with Instagram Live Producer. Keys are temporary and usually must be generated for each live session.

🎵 TikTok

TikTok Live/RTMP access depends on account eligibility or Live Center access. Use the RTMP URL/key shown by TikTok when available.

Protect stream keys: do not commit keys to GitHub. Enter them only on your own tablet and relay over HTTPS.
