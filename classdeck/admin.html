HMG License Generator

Private admin tool — generate HMG ACCESS KEYS for paying teachers. Keep this page private. The static browser generator is convenient for local use, but browser code can be inspected; use the optional Cloudflare Worker for production licensing.

How the revenue flow works (all free tools)

1. A teacher tries CLASS DECK — they get a 3-day free trial automatically.
2. To continue, they pay your small fee (Paystack/Flutterwave payment link, bank transfer, POS — your choice).
3. You type their name + expiry here → send them the key on WhatsApp.
4. They enter name + key once in the Teacher Studio → licensed until expiry.
5. Renewal = new key with a later expiry. Students never pay and never see any of this.
