Storage manager

How we stay inside the free 500 MB database + 1 GB file space

We never upload lesson files into Postgres. Photos, passports, recordings, PDFs and videos are https / Google Drive / YouTube links (previews via media.js). That keeps the database for rows only (names, scores, bookings).

Cold rows (old activity logs, read notifications, old CBT attempts) can be exported as a SHA-256 sealed archive (Admin Data) and then purged. Optional: run database/storage-offload.sql once to create private archives and proctor buckets on Supabase File Storage (1 GB, separate from the 500 MB DB) — still no public lesson-file dump.

Google Drive sync (GIS + drive.file) stores the sealed backup on your Drive. See docs/GOOGLE-DRIVE-SYNC-GUIDE.md.
