Class registration links🎓 Staff only

Create ONE short, shareable link for a class — paid or free — and post it on your social media handles: WhatsApp, Facebook, X, LinkedIn, Telegram, email, or as a QR code on a flyer. The link opens a clean public registration page (class-register.html?code=…) that shows the class, its price (or that it is free), when it runs and where, and lets a parent register in under a minute with a registration number on the spot. Every link tracks its own usage, and every registration is captured with its funnel status (new → contacted → booked → converted), so you can see which handle actually brings families. What you can do here: Create link, Share, Preview, Close / reopen, Manage registrations. Requires sign-in as staff.

Who it is for. The owner, admin and tutors who advertise classes on social media.

Why it matters. A parent who reads about your class on WhatsApp should not have to hunt for a form or create an account — one tap on a link should open everything and capture the registration. This is the difference between an enquiry and a booked seat.

How to use this page
  1. Press ＋ New class link and fill the class details — type (paid or free), title, subject, price if paid, schedule, platform, image and a short intro.
  2. Press Save link — the share card appears instantly with pre-filled WhatsApp / Facebook / X / LinkedIn / Telegram / Email buttons, a copy-link button and a QR code.
  3. Post the link on your handles. You can also open Preview page to see exactly what a parent sees.
  4. Watch usage on each link and open Registrations to follow up — mark each one contacted, booked or converted.
  5. Close the link when the class fills, or let it expire.
What each role sees here
  • Owner: Full access to every link and registration.
  • Tutor: Full access to the links they created, and their registrations.
  • Parent: No access — parents use the public registration page.
  • Learner: No access.
