About

Class Deck📡 Live class

Full HMG Academy Class Deck is integrated into this studio: split-screen whiteboard + materials, built-in live classroom, Meet/Zoom/Teams companion mode, student join links, quizzes & leaderboards, toolkit, and no-OBS social live — no AI API.

Who it is for. Tutors run the teacher studio; learners join free with a room code or link; admins can bookmark room URLs on session rows.

Why it matters. You no longer leave Tutoring Connect for a separate teaching app. Session → Class Deck → attendance/scores stay in one practice.

What each role sees here
  • Owner / admin: Full hub and Class Deck runtime; can store join URLs on sessions.
  • Tutor: Opens Teacher Studio and companion mode; shares join links with their learners.
  • Parent: No teacher studio; may open a join link they were sent.
  • Learner: Joins free via room code/link — no portal account required for the live room.

How to attach Class Deck to a Tutoring Connect session

  1. Open Teacher Studio and note your room code (or set a custom code in Class Deck settings).
  2. Copy the student link: classdeck/join.html?room=YOURCODE (same origin as this portal).
  3. Paste that URL into the session’s Meeting URL field (Sessions / Calendar) or send it on WhatsApp.
  4. Start Meet/Zoom if you want companion mode, share entire screen, then teach inside Class Deck.
  5. After class, mark attendance and complete-a-class as usual in Tutoring Connect.

Bundled runtime path: /classdeck/ — full upstream feature set (whiteboard, toolkit 200+, live classroom, activities, behaviour points, captions, PiP). See classdeck/docs/FEATURES.md.
