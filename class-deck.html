ADEWALE CLASSROOM DECK📡 Live class

ADEWALE CLASSROOM DECK is the live-teaching workspace built into ADEWALE CLASSROOM — split-screen whiteboard and materials, built-in live classroom, Meet/Zoom/Teams companion mode, free student join links, toolkit, quizzes and leaderboards. Created by Adewale Samson Adeagbo (HMG Concepts Ecosystem). No separate deck login for teachers: your ADEWALE CLASSROOM portal session is enough. No AI API.

Who it is for. Tutors and the studio owner run the teacher studio. Learners join free with a room code or invite link — they do not need a portal account for the live room.

Why it matters. Delivery, attendance and scores stay inside one studio. You teach live, then mark attendance and complete-a-class as usual.

How teachers start (no second login)
  1. Sign in to ADEWALE CLASSROOM (you are already here if you see this page).
  2. Open Teacher Studio below — the portal session unlocks it automatically.
  3. Copy the student join link (classdeck/join.html?room=CODE) into the session Meeting URL or WhatsApp.
  4. Optional: start Meet/Zoom, share entire screen, open Meet companion so Android does not kill split-screen.
  5. After class, return to Sessions → attendance → complete-a-class.
What each role sees here
  • Owner / admin: Full hub and studio; can store join URLs on any session.
  • Tutor: Opens Teacher Studio with the same portal login; shares join links with their learners.
  • Parent: No teacher studio; may open a join link they were sent so their child can enter the room.
  • Learner: Joins free via room code/link — no ADEWALE CLASSROOM account required for the live room.

Sync with ADEWALE CLASSROOM data

  • Sessions / calendar: paste classdeck/join.html?room=YOURCODE into the session Meeting URL so families see one join button.
  • Class registration links: add the same join URL on a paid/free class link when the live room is the delivery channel.
  • Attendance & hour banks: after the live class, mark attendance and complete-a-class as usual — Deck does not replace those ledgers.
  • CBT: for graded quizzes use ADEWALE CLASSROOM Quizzes / Take a quiz; Deck’s in-room quizzes are for formative live checks.
  • Identity: teachers = portal profiles; learners in-room can use display names, then map to learner records when you mark attendance.
