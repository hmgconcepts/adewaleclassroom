Site license

Site license🛡️ Owner / admin only

Lifetime or subscription lock. Same idea as School Connect, adapted. The main actions available here are: Sign out, Theme. Owner/admin only. These pages control money, safeguarding, audit or platform configuration, so they sit behind the highest role check.

Who it is for. Owner and admin. This is configuration and governance, not day-to-day teaching.

Why it matters. Configuration decides who can see what. A mistake here is a privacy incident, so every change is written to the activity log.

How to use this page
  1. Only an owner or admin should change anything on this page.
  2. Read the note beside each setting before you touch it.
  3. Save, then reload any normal page to confirm the change took effect.
  4. If something looks wrong afterwards, the activity log records who changed what and when.

🛡️ Licence status

These figures come from the database, not from this page's own arithmetic. That distinction matters: before V17 the licence was evaluated in the browser and enforced by drawing a box over the screen, which anyone could delete with F12. Enforcement now happens in PostgreSQL, on 27 operational tables, where the browser cannot argue with it.

💳 Licence model

Tutoring Connect supports both commercial models the generator offers. Change it here at any time — the studio is never rebuilt.

A one-time licence is never nagged, never locked and ignores the expiry date entirely, whatever the enforcement setting says.
Free text shown to the owner. Purely descriptive.
The studio keeps working during grace.
Reads are never blocked in any mode. An expired studio can always be read, printed and exported. Holding a client's own data hostage would be indefensible, so it is not an option this software offers.

🔄 Renew

Renewing early extends the existing term rather than truncating it, and renewing late starts from today, so nobody is billed for a period they could not use.

🧪 Test the enforcement

Proves the guard is real rather than asking you to take it on trust. This attempts a harmless write and reports exactly what the database said back.
