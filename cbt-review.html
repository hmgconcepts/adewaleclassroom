Review my paper🔑 Quiz code + student ID

Open your latest attempt for any quiz: every question, your answer, the correct key, the explanation, diagrams/media, subject breakdown, filters, calculator, maths keyboard, and a printable study PDF. The gate is the quiz code plus the student ID (or guest name) you used when you sat.

Who it is for. Learners reviewing their own paper; tutors checking a candidate’s attempt with the same code + ID; parents only if the studio shares the link deliberately.

Why it matters. A score alone does not teach. Side-by-side answer / key / explanation is how gaps close before the next class.

How to use this page
  1. Enter the quiz code from your tutor (e.g. ADC-MATH-01).
  2. Enter your student ID (e.g. TC-0001) or the exact name you typed on a guest paper.
  3. Press Load my review (or Enter). Your latest released attempt appears below.
  4. Filter wrong / blank / correct, open the calculator or maths keyboard while you study, then Save / print PDF.
  5. If the paper is still being marked, auto-marked items show now; open responses appear when the tutor releases them.
What each role sees here
  • Learner: Own attempt only (code + their ID/name).
  • Tutor / admin: Can load any candidate’s attempt with that candidate’s code + ID.
  • Parent: No menu entry by default; may open a shared link if given one.
