Admin data🔐 Owner / admin only

The studio's data-custody desk. Take a sealed, checksummed backup of every table to your own device; restore one; sync a copy to your own Google Drive folder; export a single table as CSV; export an anonymised dataset for research; answer a data-subject request; and see how much of the free-tier database and storage quota is actually in use. What you can do here: Record and action the request. Owner/admin only. These pages control money, safeguarding, audit or platform configuration, so they sit behind the highest role check.

Who it is for. Owner and administrators only. This page can read every table in the studio.

Why it matters. The studio's data belongs to the studio, not to the platform it happens to run on. A backup you have never restored is not a backup, so the restore path is on the same page as the export, and every archive carries a SHA-256 checksum you can verify.

How to use this page
  1. Press Download full backup — a single JSON archive with a checksum lands on your device.
  2. Connect your own Google Drive if you want an off-device copy. Only files this app creates are ever visible to it.
  3. Use the per-table CSV export when you want one table in a spreadsheet.
  4. Use Restore to load an archive back. You are shown exactly what will change before anything is written.
  5. Watch the quota panel: the free tier gives 500 MB of database and 1 GB of storage, and this page tells you how close you are.
What each role sees here
  • Owner: Full access.
  • Tutor: No access — this page controls money, audit or configuration.
  • Parent: No access.
  • Learner: No access.

📥 Take a backup

One JSON archive containing every table this account can read, with a SHA-256 checksum so you can prove it has not been altered. It downloads to your own device — it is never sent anywhere.

📤 Restore from a backup

A backup you have never restored is not a backup. You are shown exactly what will change before anything is written, and nothing is written until you confirm.

📄 Export one table

For when you want a single table in a spreadsheet rather than the whole archive.

☁️ Copy to your own Google Drive

Optional, and free. Uses Google’s own sign-in with the drive.file scope, which can only ever see files this application itself created — it cannot read the rest of your Drive.

⚖️ Data-subject requests

When a family asks for everything you hold on their child, or asks you to erase it, do it here so the request itself is logged.
