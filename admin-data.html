Admin data🔐 Owner / admin only

The studio's data-custody desk. Take a sealed, checksummed backup of every table to your own device; restore one; sync a copy to your own Google Drive folder; export a single table as CSV; export an anonymised dataset for research; answer a data-subject request; and see how much of the free-tier database and storage quota is actually in use. What you can do here: Record and action the request. Owner/admin only. These pages control money, safeguarding, audit or platform configuration, so they sit behind the highest role check.

Who it is for. Owner and administrators only. This page can read every table in the studio.

Why it matters. The studio's data belongs to the studio, not to the platform it happens to run on. A backup you have never restored is not a backup, so the restore path is on the same page as the export, and every archive carries a SHA-256 checksum you can verify.

How to use this page
  1. Press Download full backup — a single JSON archive with a checksum lands on your device.
  2. Connect your own Google Drive if you want an off-device copy. Only files this app creates are ever visible to it.
  3. Use the per-table CSV export when you want one table in a spreadsheet.
  4. Use Restore to load an archive back. You are shown exactly what will change before anything is written.
  5. Watch the quota panel: the free tier gives 500 MB of database and 1 GB of storage, and this page tells you how close you are.
What each role sees here
  • Owner: Full access.
  • Tutor: No access — this page controls money, audit or configuration.
  • Parent: No access.
  • Learner: No access.

🚑 Disaster Recovery Wizard — restore a school onto a FRESH database from Google Drive (click to open)

When to use this: the school’s old Supabase project was paused too long / deleted / permanently lost, but backups exist in the school’s Google Drive. This wizard rebuilds everything on a brand-new database in ~30–45 minutes with free tools. (If the old project is merely paused, do NOT use this — just restore it at supabase.com and press the 💓 heartbeat on the Platform Health Console.)

  1. Create the fresh database: supabase.com → New project → copy the new Project URL and anon public key (Project Settings → API).
  2. Install the schema: new project → SQL Editor → paste the ENTIRE database/complete-schema.sql from the site files → Run → wait for “installed successfully ✅”. (This auto-installs keep-alive, the vault, Drive-sync and security settings.)
  3. Reconnect this website: edit assets/js/config.js — replace the old SUPABASE_URL and SUPABASE_ANON_KEY with the new values — push to GitHub; Vercel redeploys the SAME site onto the fresh database.
  4. Recreate the first admin: Login page → Request access → sign up; then in Supabase → Table Editor → profiles → set that row to role = super_admin, status = approved.
  5. Reconnect Google Drive: sign in here as that admin → expand ⚙️ Setup in the ☁️ Google Drive card above → paste the school’s existing OAuth Client ID (it is tied to the site URL, not the database, so the SAME one still works) → Save.
  6. One-click restore: click 📂 List Drive backups above → authorise with the school’s Google account → every past backup appears → on the NEWEST one click 🚑 Recover to new project (not plain Restore). Recovery mode imports every school record, skips dead login accounts, clears stale references, retries row-by-row, and verifies the SHA-256 seal first.
  7. Re-onboard people: staff/parents/students sign up again (send one broadcast); approve them on Approvals — restored records re-link by admission/staff number and email.
  8. Re-arm ALL safeguards: open the 🛡️ Platform Health Console → press 💓 heartbeat, re-add the two GitHub Action secrets with the NEW url/key, repoint UptimeRobot at the new project, switch Drive auto-sync back ON and run one fresh backup. Every tile must be green.

Full printable runbook with a “what survives / what doesn’t” table: docs/DISASTER-RECOVERY-RUNBOOK.md (included in this package). Prevention: keep auto-sync ON and glance at the Health Console weekly — then this wizard is never needed.
